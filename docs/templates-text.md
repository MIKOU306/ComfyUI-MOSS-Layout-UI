# 模板库与文字排版助手

版本 1.2.0。本轮完成优先计划中的第二项与第三项，不需要额外模型或依赖。

## 模板库

在「MOSS 标准提示词」节点展开「布局模板库」，选择电影海报、电商促销、杂志封面或人物介绍卡，再点击「应用模板」。元素、文案与样式会同步到相连的画布和元素管理节点。

应用会替换当前布局，请先保存需要保留的工作流或模板。未连接尺寸输入时使用模板宽高；已连接时继续使用上游输入，因此模板可能转换为不同长宽比。

- 填写名称后「保存当前为新模板」保存当前画布；「更新所选模板」替换选中的自定义模板，内置模板不可覆盖。
- 「导出模板」导出当前下拉框所选模板；「导入模板文件」将文件加入库，再点击「应用模板」使用。
- 模板保存在当前浏览器、当前地址的 localStorage；不同地址、浏览器或电脑不共享。分享、清理浏览器数据或迁移前请导出文件。
- 工作流本身保存当前完整布局，重新打开已有工作流不依赖本地模板库。
- 删除或重置模板库不会清空当前画布。若存储配额或权限阻止保存，界面会显示失败；损坏的本地库不会自动被覆盖，可在保留需要的文件后手动重置。

## 文字助手

在元素管理节点选择「文字」元素，在文字内容输入框按 Enter 手动分行。下方可选择字体风格、颜色、参考字号（按生成尺寸的像素计算）、行距倍数和对齐。

空选项沿用原提示词；「清除样式」删除助手设置。文字预览使用本机字体，黑体、宋体等并不意味着 MOSS 加载了同一字体。颜色、风格和其他设置会追加为该文字项的 caption 描述，文字原文仍只保存在 text。

容量估算按全角字宽与近似半角字宽计算，复杂字体、标点、emoji 的实际宽度可能不同。提示溢出时，可扩大框、减小字号或按框宽分行。「按框宽分行」会实际写入换行，保留原有换行和字符；「撤回分行」可恢复该次操作前的文案。手动修改文字或切换不匹配的元素后，撤回按钮停用。

文字为空时，框会留在布局中，界面提示它未加入生成词；它不会再变成一个普通物体。位置锁定仍允许编辑文字和字体描述。

## 检查提示

标准提示词节点会显示：未连接画布、输入来自不同画布、空文字、预估文字溢出、生成尺寸与画布不同，以及重复安装。

尺寸检查只追踪当前提示词下游采样器的潜空间来源，不检查无关工作流。可直接读取宽高控件与 PrimitiveInt / PrimitiveNode / Reroute 链；动态计算、图像编码或复杂潜空间变换无法保证静态推断正确，会提示人工核对。诊断提供提醒，不会自动改采样器或阻止执行。

导入只接受 moss-layout/v1 的 percent_xywh 元素布局，或未标版本的兼容 elements 数组。最终给模型的 summary/items JSON 不含编辑信息，不能反向当成此格式导入。

## 保存格式

现有三节点名称、端口与 moss-layout/v1 保持兼容。文字元素可额外保存：

```json
"typography": {
  "font_style": "sans",
  "color": "#ffffff",
  "align": "center",
  "font_size": 64,
  "line_height": 1.2
}
```

这属于插件的可选编辑属性。模型只接收原有 summary/items、caption、text 与 bbox；不会接收 typography、locked 或 group_id。
