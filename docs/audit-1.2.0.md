# 1.2.0 代码审查与开发验收

日期：2026-10-23。审查覆盖三个 Python 文件、原有五个前端模块、新增模板 / 文字 / 诊断模块，以及项目元数据、示例工作流、文档和发布配置。

## 确认并修复的问题

| 问题 | 修复及验证方式 |
| --- | --- |
| x/y 为 100 时宽高可能变为 0，分组缩放存在除零风险 | 坐标预留最小 0.1%，统一前后端边界约束；边缘数据实际后端执行 |
| 非数字、null、非有限数导致后端异常，尺寸小数取整不同 | 前后端按相同规则读数与取整；跨语言契约与极值测试 |
| 背景排在前景后面时变成物体 | 按类型提取唯一背景，保留描述；跨语言与实际后端测试 |
| 合并没有背景的片段覆盖原背景，缺省字段丢失 | 分开定位背景与前景，只合并显式字段；真实界面测试 |
| elements 显式传入 [] 仍沿用旧前景 | 空数组作为有效输入；真实后端执行 |
| 空文字框被编译成普通物体 | 保留布局中的框、提示用户，模型输入跳过该项 |
| 不兼容坐标系或版本被静默当作百分比 | 导入拒绝不兼容格式，保持原布局；前端与后端测试 |
| 分组成员上下移动、定位后变成单选 | 重新选中整个组 |
| 前端解析标准 JSON 提前枚举全部嵌套对象 | 改为按需提取，优先直接解析完整 JSON |
| 元素管理一直声称已连接画布 | 根据实际连线显示独立编辑或连接状态 |
| 文字预览被框标签遮挡 | 文字框标签移到框外上方，顶部空间不足时省略标签 |

## 本轮开发范围

完成优先计划中的模板库、文字排版助手，并补齐导入、连线、尺寸、空文字和重复安装检查。保留原三节点和模型加载方式，不引入新依赖。

## 验证

详细结果及源文件哈希记录于 validation-1.2.0.json。验证包括原有 57 项编辑器浏览器回归、24 项模板 / 文字 / 诊断浏览器检查、8 项后端与重复安装检查、6 项分组与模板持久化 / 损坏保护检查，共 95 项通过。另有 14 组前后端规范化与编译契约、3 项 Python 极值与格式测试、几何单元测试和 Registry 本地配置校验通过。

四个内置模板均经过真实三节点后端编译并与前端结果比较。另执行显式空元素与边缘坐标案例，加上原编辑器持久化案例，共 7 次真实后端执行成功。重复安装提示通过模拟扩展列表验证；实际安装仍需只保留一份节点目录。

没有执行 MOSS 模型图像推理。本轮确认的是编辑、保存、导入导出、诊断与模型输入编译，不包含最终图片的文字准确率或位置服从度。动态潜空间尺寸只能在前端能够读取时检查。字体预览与容量为本机近似值，原 preview IMAGE 输出仍是布局框图。
