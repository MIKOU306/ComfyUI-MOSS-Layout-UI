# MOSS Layout UI 四项修复 · 2026-10-20

## 修复内容

1. 多套节点串数据：移除前端单例布局。每个画布拥有独立数据，元素与提示词节点按上游连线归属画布。支持标准中继、断线、重新接线、复制和删除；未连接画布的节点单独保存。工作流导入时以所属画布的保存状态为准。
2. 背景描述丢失：JavaScript 预览编译和 Python 后端编译同时将全局描述、背景描述合入 `summary.caption`。没有前景时输出两段描述；完全相同的描述只保留一次。背景不作为一个前景框输出。
3. 多行文字丢换行：文字内容编辑器改为 textarea；显示、编辑、保存、最终 `items[].text` 均保留换行。
4. 清空画布误删描述：只移除前景，保留当前尺寸、全局描述与完整背景元素。撤销恢复清空前布局，重做再次只删除前景。

保留原节点名称、接口、布局样式、百分比坐标和 `moss-layout/v1` 保存格式。未修改模型加载与采样代码。

## 实际验证

环境：隔离 ComfyUI 0.41.0、前端 1.55.18、Python 3.12.10、Chrome；后端使用 CPU，仅执行布局与提示词节点。

共 31 项检查通过：

- 两套完全不同的布局分别导入、编辑、选择；各套三个隐藏 state 保持本套一致，互不覆盖。
- 在真实元素面板输入背景；多行文字按 Enter 新增第三行，前端最终词保留背景和所有换行。
- 实际提交两个节点链到 `/prompt`，使用内置 PreviewAny 接收后端结果。两套最终词不同，且各自与前端编译结果一致。
- 保存工作流、重新打开，保留两套描述和多行文字；反序配置节点也恢复正确数据。
- 清空只删除前景，描述和尺寸保留；撤销与重做成功。背景无前景时的后端输出也保留描述。
- 元素节点断线后独立编辑，重接另一个画布后正确跟随新画布；提示词也可经 elements 追溯画布。标准 Reroute 插入和换源同步正确。
- 复制画布后独立编辑；删除另一画布不会重置剩余一套。
- 两套分别使用正方形与横版尺寸，比例与保存数据独立同步；改值后立即序列化、保存重开使用新尺寸。
- 实际鼠标用 40 次移动事件完成 `[5%,2%]` 位移，得到 `[25,27,40,30]`；撤销、重做与保存重开保留正确坐标。
- 后端使用拖后的方形布局及另一套横版布局编译，bbox 与前端一致。

总计 3 次真实后端执行均成功。详细检查、输出和所测源码 SHA-256 见同目录 `validation-1.0.1.json`。发布源码已统一为 LF 换行，七份运行源码与实测版本内容一致；JSON 摘要按发布文件计算，不包含 README。

本次没有重新运行 MOSS 大模型出图，验收覆盖编辑、状态保存、连线归属与实际模型输入提示词。布局框对最终生成画面的约束效果仍取决于模型。
